> **Zero installs. Zero waiting.** DuelVerse is a web-based, real-time 1v1 multiplayer gaming platform inspired by mobile arcade hits like *2 Player Games: The Challenge*. Play cross-device with friends via scannable QR codes and 6-character room codes, or battle against the **CyberBot Master AI**.

---

## 🎮 The 10 Arcade Games

1. **💥 Tank Duel**: 60 FPS armored tank combat featuring barricade cover, ricochet laser physics, and tactical CyberBot strafing.
2. **🏃 Obstacle Rush**: 2.5D gauntlet sprint past rotating hammers, moving bumpers, and disappearing floor tiles.
3. **🔴 Connect Four**: Gravity-based spatial duel with 4-in-a-row lookahead and trap blocking.
4. **⚡ Reaction Rush**: Millisecond reflex clash with sub-220ms signal reaction testing.
5. **🏓 Pong Battle**: High-speed cyber court air hockey with responsive paddle deflection physics.
6. **❌ Tic-Tac-Toe Duel**: Holographic 3×3 arena powered by an unbeatable Minimax algorithm.
7. **✊ RPS: Best of Five**: Synchronized secret commit clash with psychological Markov pattern prediction.
8. **🧠 Memory Match**: Photographic memory battle on a shared 4×4 card matrix.
9. **🔢 Number Blitz**: Rapid-fire mental math sprint with combo streak multipliers.
10. **🪙 Tap Frenzy**: High-speed reflex target rush with diamond sparks (+250) and skull bomb traps.

---

## 🤖 CyberBot Master AI

* **Esports-Grade Intelligence**: Unbeatable Minimax for Tic-Tac-Toe, multi-step lookahead for Connect Four, photographic memory tracking for Memory Match, and sub-220ms reflex speeds.
* **Live Arcade Commentary**: Dynamic neural core reactions, personality voice lines, and mood shifts.
* **3 Difficulty Tiers**: Casual, Pro, and Master.

---

## 🌐 Instant Cross-Device Multiplayer

* **WebRTC Peer-to-Peer**: Connects phones, tablets, and PCs directly with sub-50ms latency using STUN servers.
* **Collision-Free Room Codes**: 6-character alphanumeric room codes (`DV-XXXXXX`) offering over **1.07 billion** unique combinations.
* **Instant Mobile QR Join**: Point your phone camera at the host's screen to duel immediately on your mobile browser.
* **2-Player Window Simulation**: One-click split window mode for rapid local testing.

## 🚀 Deployment on Vercel

### Automatic CI/CD Deployment
This repository is configured for automatic deployment on **Vercel**:

1. Go to [vercel.com/new](https://vercel.com/new).
2. Select **Import Git Repository** and choose `m-venkat-11/Duel-Verse`.
3. Click **Deploy**. Vercel will automatically detect Vite and use `vercel.json` for SPA route rewrites.
4. **Done!** Every commit and push to `main` will automatically trigger an instant production build and deployment.

## 🛠️ Local Development

```bash
# Clone repository
git clone https://github.com/m-venkat-11/Duel-Verse.git
cd Duel-Verse

# Install dependencies
npm install

# Start development server
npm run dev

# Run unit test suite
npm run test

# Build production bundle
npm run build
```
